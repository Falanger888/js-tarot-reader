# 🔮 Интерактивное Таро

Легковесное интерактивное веб-приложение для расклада карт Таро, созданное полностью на чистом JavaScript, HTML5 и CSS3. Без использования сторонних фреймворков и библиотек.

## 🚀 Особенности
- **Модульная архитектура:** Четкое разделение данных (`data.js`), логики приложения (`app.js`) и интерфейса (`index.html` / `style.css`).
- **Честная тасовка:** Используется алгоритм Фишера-Йетса на базе Web Crypto API (`crypto.getRandomValues`) для обеспечения истинной случайности.
- **CSS 3D-анимации:** Плавный эффект переворота карт с помощью `transform-style: preserve-3d` и `backface-visibility`.
- **Доступность (a11y):** Полная навигация с клавиатуры (клавиша `Tab` для фокуса, `Enter` или `Пробел` для переворота карты) и правильные ARIA-атрибуты.
- **Делегирование событий:** Оптимизированные обработчики событий для лучшей производительности.
- **Адаптивный дизайн:** Корректно отображается как на ПК, так и на мобильных устройствах.

## 🎮 Как использовать
1. Скачайте или склонируйте этот репозиторий.
2. Откройте файл `index.html` в любом современном браузере.
3. Введите свой вопрос, выберите расклад (3 карты, 5 карт или «Два пути») и нажмите «Разложить».

## 🛠️ Стек технологий
- **Язык:** JavaScript (ES6+)
- **Разметка:** HTML5
- **Стили:** CSS3 (кастомные свойства, Grid, Flexbox, 3D-трансформации)
- **Безопасность:** Экранирование HTML для защиты от XSS-атак
